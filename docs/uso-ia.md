## Herramienta y para qué se usó

Se usó un asistente de IA integrado con Copilot en VS Code para trabajar en la
propuesta y en una primera versión del catálogo y la API. El propósito fue apoyar
el aprendizaje de Angular, las API REST, Mongoose y la autenticación con Express.

## En qué partes ayudó

- Organizar la propuesta, los módulos, los roles y las cinco entidades.
- Preparar modelos, rutas, controladores y middlewares del backend.
- Desarrollar una primera versión de registro, inicio de sesión y permisos JWT.
- Conectar el catálogo de Angular con la API y agregar búsqueda, filtros y detalle.
- Preparar instrucciones y ejecutar verificaciones técnicas.
